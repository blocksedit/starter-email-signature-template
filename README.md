# Starter Email Signature Template
### HTML template of an email signature with standard contact details

Similar to a business card, an email signature can work as a way to provide added contact info in emails you send out along with relevant links.

## Features

- Features
- Responsive across screen sizes
- Dark mode compatibility
- Semantic code, optimized for accessibility
- Blocks Edit ready for drag and drop editing
- Legacy Outlook code version
